Anaconda - это дистрибутив Python содержащи1 большую часть библиотик, который не стоят по изначалу в Python

Многие библиотеки могцт начать конфликтовать с языком, из-за чего нужно уметь ставить виртуальную среду под Anaconda

Создать среду Python 3.6 c именем "dsfs

 - conda create -n dsfs python=3.6

Для активации активной среды используйте
 - source activate dsfs

Для деактивации активной среды используйте 
 - source deactivate


После активация виртуальная среда должна настроиться под дистрибутив Anaconda, будет выглядить примерно так:

(dsfs) ip-10-0-0-198:~ joelg$

Все библиотеки которые будут устнавливаться в среде будут работать только в ней
